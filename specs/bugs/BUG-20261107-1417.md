# BUG-20261107-1417: Nix checks miss dependencies required by the current release

## Summary

After merging upstream `f8e877d`, the Nix package cannot run the new
transport-recovery test, and the development shell cannot load D-Bus test binaries.

## Reproduction

- `nix flake check .` fails in
  `removed_controller_exits_and_relaunch_advertises_on_replacement` with
  `private D-Bus: Os { code: 2, kind: NotFound, message: "No such file or directory" }`.
- `nix develop . --command make test` fails to load `libdbus-1.so.3`
  when starting `tests/bluer_smoke.rs`.
- The release-script tests also failed without `openssl` in the development shell.
- Adding an assertion for the upstream service's `StartLimitIntervalSec=0`
  fails NixOS evaluation with `attribute 'StartLimitIntervalSec' missing`.

## Expected Behavior

The Nix package and development environment run the current workspace tests,
and the NixOS user unit preserves upstream's controller-recovery restart policy.

## Root Cause Analysis

The transport-recovery test spawns `dbus-daemon`, which was absent from native
check inputs. Development test binaries lack an installed RPATH, so they need
the D-Bus library on their loader search path. The shell omitted OpenSSL.
The separately declared NixOS unit omitted upstream's disabled start-rate limit.
An isolated `runCommand` probe then exposed the daemon's hidden stderr:
`Failed to open "/etc/dbus-1/session.conf": No such file or directory`.
The configuration is installed under the D-Bus store path instead.

## Fix

Provide a native check wrapper selecting the store's session configuration,
expose the D-Bus library path in the shell,
provide OpenSSL, and match the upstream unit's start-limit setting. Keep a
NixOS evaluation assertion for that setting. Update Nix installation examples
and package metadata to the current upstream repository.

## Traceability

- S-022 / S-023 in `specs/syauth/ROADMAP.md`.
- Regression: `crates/syauth-presenced/tests/transport_recovery.rs` and `nix/check.nix`.
- Fix: `nix/package.nix`, `flake.nix`, `nix/modules/nixos.nix`.

## Validation

  and the NixOS start-limit assertion.
- `nix develop . --command make lint` passes.
- `make test` in the development shell: 460 passed, 10 ignored, zero failures.
- Release, installer, and update-check Python suites: 52 passed.
- All seven pre-commit hooks and the strict documentation build pass.
