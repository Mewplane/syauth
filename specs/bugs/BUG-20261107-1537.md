# Release installation links still point to the former repository owner

## Summary

The installer command and installation guide return HTTP 404 after the
repository moved to Mewplane.

## Reproduction

HEAD requests to `https://dmytrogajewski.github.io/syauth/install.sh` and
`https://dmytrogajewski.github.io/syauth/how-to/install/` return 404.
GitHub Pages reports `https://mewplane.github.io/syauth/` as the deployment URL,
and its installer returns 200. The new installer owner regression fails on
the former API repository path.

## Expected

Release instructions reach the published installer and current repository.

## Actual

The documented installer and guide are unavailable at their former addresses.

## Root Cause

Published URLs retained the former GitHub owner after the repository transfer.

## Fix

Use the current Pages address, release/API repository, package homepage, and
documentation source links. Keep the existing package verification and approval
requirements.

## Traceability

`tests/test_installer.py::InstallerTests::test_downloads_and_guidance_use_the_current_repository_owner`
checks the API lookup, download origin, and final setup guidance through the
real shell installer. It failed before updating those addresses.
